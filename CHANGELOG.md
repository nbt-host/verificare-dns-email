# Changelog

## 1.0.0

First public release.

- DNS and email check: NS, A, AAAA, MX, SPF (with the 10-lookup count, nested includes counted), DKIM (several selectors tried automatically, key size shown), DMARC, CAA.
- SPF and DMARC generator, fully offline.
- Interface in Romanian (root) and English (`en/`).
