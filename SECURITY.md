# Security

The tool runs only in the browser and has no server side. If you find a way to make it run code, leak data or send requests anywhere other than the public DNS-over-HTTPS resolvers, please write to **suport@nbt-host.com** instead of opening a public issue. We reply on working days.

This address is for this open source tool. Problems with NBT Host hosting accounts go through the normal support channels on [nbt-host.com](https://nbt-host.com/).
